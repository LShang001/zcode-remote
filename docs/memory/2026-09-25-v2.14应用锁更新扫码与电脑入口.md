# 2026-09-25 v2.14 应用锁、更新下载与多电脑体验

- 应用锁开启时，冷启动先显示遮挡层，认证完成后才路由远程链接与恢复更新；移除生物识别弹窗的“跳过”，允许用设备屏幕锁验证，未设置解锁方式不能开启应用锁。Android 13+ 禁止最近任务生成本页截图。
- 外部链接、扫码和桌面快捷方式优先于旧剪贴板链接；同链接从错误页返回统一走 `showWeb` 重载判定，避免掀开覆盖层露出 WebView 错误页。

- DownloadManager 完成广播先查状态：成功才验签、失败继续换源；不同尝试使用不同文件名，进程重启恢复镜像下标与轮次。APK 拷贝和验签移到工作线程，结果返回主线程处理；安装包不存在时清理挂起状态。
- 相册扫码的 Otsu 类间方差改用不会在常规大图上溢出的运算；相册选图和相机帧用代数标记隔离结果，扫码状态改为常驻文字。X200 尺寸模拟器验证了电脑操作入口、应用锁取消后没有 WebView，以及相册密集二维码识别回传；镜像下载/安装权限仍需目标真机验证。
