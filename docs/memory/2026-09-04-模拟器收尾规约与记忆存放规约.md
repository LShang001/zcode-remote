# 2026-09-04 — 模拟器收尾规约与记忆存放规约

- **模拟器不会自动关**:android-emulator 插件设计为"复用热机、按需启动、从不自动停",任务结束后进程会一直常驻(约 2-3GB 内存)。当天发现一个凌晨 3:00 启动的遗留实例挂了数小时。规约:凡用过模拟器,收尾必须主动问用户"关不关";关则 `android_stop_emulator` + `adb devices` 确认清空。
- **全链路验证可行**:构建(约 1 分钟内,缓存命中秒级)→ `adb install` 流式安装 → 启动 → 插件截图(超 200KB 会落盘成 artifact 文件,用 Read 读图)→ 模拟点击 → 再截图,整条链路无需人工介入。
- **插件截图两形态**:小图直接内联返回;大于内联上限(约 200KB)时存到 `%USERPROFILE%\.zcode\cli\artifacts\<会话>\*.png`,工具返回里给 Artifact 路径,需要用 Read 打开看。
- **记忆存放规约(用户指定)**:所有记忆必须落项目共享位置——`docs/memory/` 日期笔记 + AGENTS.md 耐久规则,agent 私有记忆只作索引补充,保证其他 agent 工具(Claude Code / Codex / Cursor)可见。沉淀协议 P1 已改为"直接同步,不再追问"。
- 过期会话链接在 WebView 里显示网页自己的 "Mobile Connection Invalid" 错误页属预期行为(网络通,只是 sid 过期),不要误判为壳的 bug。
