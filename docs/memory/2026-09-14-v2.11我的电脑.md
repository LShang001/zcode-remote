# 2026-09-14 v2.11「我的电脑」多机切换

用户提出:不同会话链接 = 不同电脑上的 ZCode,希望做成更方便切换的形式(含历史与命名)。
原"历史会话"对话框重构为按电脑维度的切换器。耐久模型已写进 AGENTS.md §核心模型。

## 要点

1. **数据模型**:`{url, name, time}` 三元组,name 为显示名。`deriveName` 从链接参数派生
   (name > mid > sid 前缀 > "远程会话"),所以**不做数据迁移**——老记录读出来自动有名字。
2. **命名优先级**:用户改名后 `recordHistory` 不得覆盖 name(否则每连一次就被打回派生名)。
3. **交互**:点=切换(同链只回覆盖层不重载)、长按=重命名/删除、当前那台高亮 + "● ... 当前"。
   改名/删除后要重开对话框刷新列表;`saveHistory` 统一触发动态快捷方式同步(快捷方式标签=电脑名)。
4. **措辞统一**:所有 UI 文案从"会话"改口径为"电脑"(菜单项、头部"当前控制:X"、空态、设置页提示);
   新加文案沿用,避免两套词并存。
5. **模拟器验证**:用 VIEW intent 连推多条不同 `sid/mid/name` 链接模拟多台电脑
   (`adb shell "am start -n ... -a VIEW -d '...&mid=X'"`——整串要包在引号里,否则 `&` 后的参数
   被设备 shell 截断);`input text` 不支持中文,改名验证用 ASCII 名。
6. `dumpsys shortcut` 可验证动态快捷方式标签是否跟着改名同步(session_0/session_1)。

## 验证覆盖

三台电脑模拟(VISIO 名派生 name/mid/sid 三种路径)、切换后 prefs 与"当前"标记转移、长按重命名落库
并刷新列表与快捷方式、删除确认后列表更新、老格式数据(无 name 字段)正确派生,全程无崩溃。
