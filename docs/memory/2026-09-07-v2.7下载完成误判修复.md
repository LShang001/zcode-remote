# 2026-09-07 v2.7 修复"下载完成却被判失败、循环重下"

- **真机症状**(用户反馈 v2.6):更新下载明明完成,App 却一直提示下载失败、反复换源重新下载。
- **根因**(模拟器 logcat 实锤):Android 14+/targetSdk 34 下读 `DownloadManager.COLUMN_LOCAL_FILENAME` 抛 `SecurityException: COLUMN_LOCAL_FILENAME is deprecated; use ContentResolver.openFileDescriptor() instead`;旧代码 `catch (Exception ignored)` 吞掉 → path=null → verifyAndInstall 走"源失败"分支 → failDownload 换源重下;每次下载都真实完成,每次都被判失败,10 次轮转后报最终失败。
- **修复**(Updater.java):①完成态统一走 `scheduleVerify`(1.2s 落盘缓冲 + 轮询/广播去重);②路径列拿不到/读不到时经 `getUriForDownloadedFile`+`openInputStream` 拷入私有缓存再验签(不依赖存储权限与路径列);③魔数(PK)预检区分"内容真是垃圾"(可换源)与"设备读不到/解不开"(保留文件、阻断提示、绝不换源重下);④验签各步 `Log.i/w(TAG=ZCodeUpdater)` 留证。
- **验证**:伪装版本号法(2.4/15)装模拟器,真下载 v2.6 release 包端到端:日志复现 SecurityException → 缓存副本验签 OK → 安装权限引导 → 授权回App自动续装 → 系统安装器弹"是否更新",全链闭环。
- **发版**:v2.7(versionCode 18),commit 771447a,Release 已建;踩坑进 AGENTS.md §踩坑记录。
